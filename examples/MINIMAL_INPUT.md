# Example — Starting With Almost Nothing

This example shows the intended interaction when the user has only a rough idea.

## User starts with

```text
I want to create a visual identity for a new coffee delivery service for university students.
```

The user uploads `MASTER_BRAND_IDENTITY_OPERATING_SYSTEM.md` and sends the recommended start command.

## What should happen

ChatGPT should **not** immediately respond with:

- brown + cream palette
- coffee-bean logo
- three arbitrary logo images
- “modern minimalist” typography

Instead it should inspect what is known and begin adaptive discovery.

A reasonable first question might investigate the project/offer and why it needs an identity now.

After the answer, the AI chooses the next highest-impact unresolved field rather than dumping the complete question bank.

## Example discovery progression

This is illustrative, not a fixed script:

```text
Project / offer
      ↓
Primary audience and decision context
      ↓
Alternatives / differentiation
      ↓
Desired and undesired perception
      ↓
Priority touchpoints and constraints
      ↓
Brand Brief Sufficiency Gate
```

If the user's answers naturally resolve multiple fields, later questions should be skipped.

## Then

The AI synthesizes an operational brief and asks the user to correct strategic/factual interpretation.

After the brief is sufficient, the workflow continues into:

1. category/audience research
2. visual-landscape/differentiation research
3. production/platform research
4. strategy
5. creative territories
6. direction selection
7. full identity system
8. relevant touchpoint validation
9. production assets/editable master
10. final QA and handoff

## Key lesson

The operating specification enables a user to start without knowing professional branding terminology.

The AI should create structure around the user's real project rather than making the user invent a fake brief before the conversation can begin.

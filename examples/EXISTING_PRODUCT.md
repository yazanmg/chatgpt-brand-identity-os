# Example — Existing Product With UI/UX

This example covers a project that already has a real product but no formally documented brand identity system.

## Starting material

The user uploads:

- product brief
- several UI screenshots
- current app icon
- current logo
- design tokens or theme values
- product documentation

Then uploads the canonical operating specification and uses the normal start command.

## What should happen

The AI should inspect the supplied evidence before asking questions.

It should identify visual/product behaviors that already carry meaning and classify significant elements as:

- `KEEP`
- `EVOLVE`
- `REPLACE`

Examples might include:

- an established accent color with recognition
- a useful recurring geometry
- an inaccessible semantic color
- inconsistent typography
- an app icon that no longer fits the product family

## What should **not** happen

The AI should not ignore years of real product evidence and replace everything with a fashionable generated moodboard simply because the new concept looks more polished.

Existing work is evidence, not automatically sacred and not automatically disposable.

## Discovery

Questions should focus only on meaningful gaps that the product material cannot answer, such as:

- why the identity is being formalized now
- what recognition/equity must be preserved
- what users currently misunderstand
- future product-family plans
- which stakeholders approve the change

## Creative work

Research and creative territories should be informed by the existing product reality.

Each direction should be tested on representative product surfaces rather than only generic stationery mockups.

## Production outcome

Depending on scope, the final system may include:

- refined master mark / wordmarks
- product-family logic
- semantic color architecture
- typography hierarchy
- icon/graphic language
- app icons
- accessibility/localization rules
- design tokens
- updated product examples
- editable Figma master
- vector exports
- guidelines and handoff

## Key lesson

A mature product can contain a latent brand DNA before anyone has written a brand manual. The workflow is designed to find and formalize that DNA rather than starting from a blank page unnecessarily.

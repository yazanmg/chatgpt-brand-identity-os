# ChatGPT Conversation — Not Codex

This repository is designed for **normal ChatGPT conversations**.

It is not intended to be used as:

- a Codex system prompt
- `AGENTS.md`
- coding-agent repository instructions
- a code-generation policy file
- a CI/CD coding workflow

## Why the distinction matters

The operating specification is built around an interactive creative relationship:

```text
User context / project evidence
        ↓
ChatGPT inspects
        ↓
ChatGPT asks only needed discovery questions
        ↓
User answers / corrects
        ↓
Research and strategic synthesis
        ↓
Creative territories
        ↓
User selects / corrects direction
        ↓
Production system
        ↓
Editable Figma / handoff / QA
```

Brand identity decisions often require progressive human correction and creative approval. The workflow therefore assumes a normal conversation where the user can inspect and react to intermediate work.

## Recommended environment

Use a normal ChatGPT chat where you can:

- upload the canonical `.md`
- upload project files
- share screenshots/images
- discuss strategy
- compare creative directions
- use web research when needed
- use image generation during exploration when available
- use Figma integration/tools when available
- receive downloadable production files when generated

## What Codex is good at

Codex and coding agents are useful when the task is software/repository implementation.

That is a different problem from the end-to-end conversational brand-identity process this repository was built to govern.

If the completed identity later needs code implementation, the resulting brand rules, tokens, components, and assets can of course become inputs to software-development workflows.

The **identity creation workflow itself**, however, is intended for normal ChatGPT conversation.

## One-line rule

> Use ChatGPT Brand Identity OS to **create and productionize the identity in conversation**. Use coding tools later when you need to implement the approved system in software.

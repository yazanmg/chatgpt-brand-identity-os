# How to Use ChatGPT Brand Identity OS

This guide explains how to use the canonical operating specification in a **normal ChatGPT conversation**.

> This project is not intended for Codex, `AGENTS.md`, or repository coding-agent workflows.

## The shortest possible workflow

1. Download `MASTER_BRAND_IDENTITY_OPERATING_SYSTEM.md` from this repository.
2. Open a normal ChatGPT conversation.
3. Upload the `.md` file.
4. Upload any project material you already have.
5. Send the start command below.
6. Answer discovery questions when ChatGPT needs information that cannot be obtained from the supplied material.
7. Review and correct the synthesized brief.
8. Compare creative territories when the project requires broad exploration.
9. Select/correct a direction.
10. Continue through production, editable master/Figma, QA, and handoff.

## Recommended start command

```text
Use MASTER_BRAND_IDENTITY_OPERATING_SYSTEM.md as the governing operating specification for this project.

Read all supplied project material first.

If the brief is incomplete, conduct the adaptive discovery interview one question at a time until the Brand Brief Sufficiency Gate passes.

Then continue through the complete professional brand identity workflow, including research, strategy, creative territories, production, editable master/Figma workflow, QA, and handoff as applicable to the real project.

Use STRICT MODE.
```

## You can start with almost nothing

You do not need to write a professional brand brief first.

Valid starting points include:

- a project name
- a one-sentence concept
- a rough startup idea
- a product description
- an existing logo
- screenshots
- an app or website
- existing UI/UX
- current brand guidelines
- a design system
- a full strategic brief

When input is sparse, the operating system tells ChatGPT to create the missing brief through adaptive discovery rather than inventing business facts.

## If you already have substantial project material

Upload it first.

Examples:

- product brief
- business requirements
- UI/UX exports
- brand assets
- app icons
- design-system documentation
- screenshots
- product-family map
- typography/color rules
- packaging or signage references

Then use the same start command.

The system instructs ChatGPT to inspect supplied evidence before asking questions, so a rich project should require fewer discovery questions than a greenfield idea.

## If you already have an approved identity concept

Do not restart discovery or creative exploration unnecessarily.

Tell ChatGPT explicitly:

```text
The current visual direction is approved. Do not redesign it or create alternative concepts.

Use the operating specification to productionize the approved direction into the complete identity system, editable master/Figma file, production assets, documentation, QA, and handoff.
```

This is useful when you already love a generated brand board or concept but need to turn it into a professional production system.

## What to upload during the process

Upload evidence whenever it materially improves the identity, for example:

- screenshots of current product behavior
- existing logo/vector files
- competitor examples
- packaging dielines
- app-store assets
- typography licenses/specimens
- product architecture documentation
- implementation stack information

Do not upload private or confidential material to a public case study unless you have permission to publish it.

## What you should expect from the conversation

A healthy run normally behaves like this:

### 1. Inspection

ChatGPT reads the available material before asking you to repeat information.

### 2. Adaptive discovery

If critical gaps exist, it asks one high-value neutral question at a time.

### 3. Brief synthesis

ChatGPT turns evidence and answers into an operational brand brief and gives you a chance to correct factual/strategic misunderstandings.

### 4. Research

The system separates research into category/audience, visual differentiation, and production/platform requirements.

### 5. Creative exploration

When broad exploration is justified, ChatGPT develops structurally different territories and compares them on the same benchmark surfaces.

### 6. Selection

You choose or correct the major direction before the final production system is built.

### 7. Systemization

The selected direction expands into the applicable logo, color, typography, iconography, graphic language, product-family, imagery, accessibility, localization, motion, token, and production rules.

### 8. Real-world validation

The identity is applied to the actual high-priority touchpoints rather than only decorative mockups.

### 9. Editable production master

When Figma is appropriate and available, the workflow aims for a real editable Figma system rather than a screenshot in a frame.

### 10. QA and handoff

The operating specification uses completion gates and three independent final review passes before the work is allowed to be called final.

## What not to do

Avoid these instructions unless you intentionally want a shortcut:

```text
Skip discovery and make me a logo.
```

```text
Just use whatever colors look modern.
```

```text
Give me one image and call it finished.
```

They defeat the main purpose of the system.

## Normal Mode vs STRICT MODE

For serious projects, use `STRICT MODE`.

Normal conversational flexibility is useful for experimentation, but STRICT MODE is designed to reduce silent assumptions, skipped phases, unverified standards, and premature `FINAL` claims.

See [`STRICT_MODE.md`](./STRICT_MODE.md).

## Figma

If you want a professional Figma handoff, say so before production finalization.

The operating specification contains a resilience strategy for direct Figma automation, plan/page constraints, and a local Figma Development Plugin fallback.

See [`FIGMA_WORKFLOW.md`](./FIGMA_WORKFLOW.md).

## Remember

The `.md` file is the operating specification.

The conversation is the working environment.

Your project evidence is the source material.

The goal is not to make the AI produce more images. The goal is to make the complete identity process more disciplined, reproducible, and production-ready.

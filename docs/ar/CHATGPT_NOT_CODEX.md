# ChatGPT وليس Codex

[English](../CHATGPT_NOT_CODEX.md) | [العربية](./CHATGPT_NOT_CODEX.md)

هذا المشروع مصمم للعمل داخل **محادثة ChatGPT عادية**، وليس داخل Codex أو Coding Agent.

## البيئة المقصودة

- ChatGPT Web
- ChatGPT Desktop
- ChatGPT Mobile
- محادثة عادية يمكن رفع ملفات المشروع إليها
- استخدام أدوات الصور والويب وFigma عندما تكون متاحة

## لماذا ليس Codex؟

لأن هذا الـOperating System مبني على حوار إبداعي تدريجي:

```text
تفهم المشروع
↓
تسأل المستخدم
↓
تبحث
↓
تعرض اتجاهات
↓
يختار المستخدم / يصحح
↓
تنتقل للإنتاج
↓
Figma + Handoff
```

أما Codex فتركيزه الأساسي على البرمجة، المستودعات، الملفات البرمجية، والتنفيذ الهندسي.

## ماذا تفعل؟

1. افتح محادثة ChatGPT عادية.
2. ارفع `MASTER_BRAND_IDENTITY_OPERATING_SYSTEM.md`.
3. ارفع أي ملفات متوفرة عن مشروعك.
4. أرسل Start Command الموجود في README.
5. إذا أردت Figma كشرط نهائي، أرسل أيضًا [`FIGMA_REQUIRED_FINAL_OUTPUT.md`](./FIGMA_REQUIRED_FINAL_OUTPUT.md).

## ما الذي لا تفعله؟

لا تستخدم هذا الملف كبديل لـ:

- `AGENTS.md`
- Codex repository rules
- Coding system prompt
- CI configuration

هذا المشروع للـBrand Identity داخل المحادثة.
